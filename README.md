# LIXIL Auto Report

คู่มือใช้งานสำหรับผู้ดูแลทีมและผู้ใช้งานทั่วไป  
โปรแกรมนี้ใช้สำหรับนำเข้าไฟล์รายงานจาก Cisco UCCX แล้วแปลงเป็นรายงานสรุปพร้อมตาราง/กราฟ และ export เป็นไฟล์ Excel ได้จากหน้าเว็บบนเครื่องตัวเอง

> โปรแกรมนี้ออกแบบให้รันแบบ local บนเครื่องลูกค้า ข้อมูลรายงานจะไม่ถูกส่งขึ้น online

---

## ✅ สิ่งที่ต้องมี

ก่อนเริ่มใช้งาน ตรวจสอบว่ามีสิ่งเหล่านี้แล้ว:

- 🖥️ เครื่อง Windows
- 🐍 Python 3.10 ขึ้นไป
- 📁 โฟลเดอร์โปรแกรม `lixil_report_app`
- 📄 ไฟล์รายงานดิบจาก Cisco UCCX/CUIC/CAR สำหรับนำเข้า

---

## 📦 วิธีดาวน์โหลดโปรแกรมจาก GitHub

1. เปิดเว็บ GitHub repo:
   <https://github.com/aclayer8/lixil-autoreport>

2. กดปุ่มสีเขียว **Code**

3. กด **Download ZIP**

4. แตกไฟล์ ZIP ไปไว้ในเครื่อง เช่น:

   ```text
   C:\LIXIL\lixil-autoreport
   ```

5. เปิดเข้าไปที่โฟลเดอร์:

   ```text
   lixil-autoreport\lixil_report_app
   ```

---

## 🛠️ ติดตั้งครั้งแรก

ทำแค่ครั้งแรกครั้งเดียว

1. เข้าโฟลเดอร์ `lixil_report_app`

2. ดับเบิลคลิกไฟล์:

   ```text
   setup.bat
   ```

3. รอจนหน้าต่างติดตั้งทำงานเสร็จ

4. ถ้าหน้าต่างขึ้นข้อความให้กดปุ่มใดก็ได้ ให้กด Enter

หลังจากนี้ไม่ต้องกด `setup.bat` ซ้ำ ยกเว้นลงเครื่องใหม่หรือโฟลเดอร์โปรแกรมถูกลบ

---

## 🚀 วิธีเปิดโปรแกรมใช้งาน

1. เข้าโฟลเดอร์:

   ```text
   lixil_report_app
   ```

2. ดับเบิลคลิกไฟล์:

   ```text
   run_server.bat
   ```

3. จะมีหน้าต่างสีดำเปิดขึ้นมา ให้เปิดค้างไว้ ห้ามปิดระหว่างใช้งาน

4. เปิดเว็บเบราว์เซอร์ เช่น Chrome หรือ Edge

5. เข้า URL นี้:

   ```text
   http://127.0.0.1:5000/
   ```

6. จะเห็นหน้าโปรแกรม LIXIL Reports Auto

---

## 📊 วิธีสร้างรายงาน

1. เปิดหน้าโปรแกรมที่:

   ```text
   http://127.0.0.1:5000/
   ```

2. เลือกเมนูรายงานด้านซ้าย เช่น:

   - `CSAT Report`
   - `1.1 CSQ Day`
   - `1.6 Not Ready Count`
   - `1.11 Reserved/Talking Ratio`

3. กดปุ่ม **Import Data**

4. เลือกไฟล์รายงานดิบจากเครื่อง

5. รอโปรแกรมประมวลผล

6. หลังประมวลผลเสร็จ จะเห็นตาราง/กราฟบนหน้าจอ

7. กดปุ่ม **Export Data** เพื่อดาวน์โหลดไฟล์ Excel

---

## 🧹 วิธีล้างข้อมูลหน้าจอ

ถ้าต้องการล้างข้อมูลที่ import แล้ว:

1. กดปุ่ม **Clear Data**

2. หน้าจอจะกลับไปเป็นหน้ารายงานว่าง

3. สามารถกด **Import Data** เพื่อเลือกไฟล์ใหม่ได้ทันที

---

## 🧭 ปุ่มในโปรแกรม

| ปุ่ม | ใช้ทำอะไร |
|---|---|
| 📥 Import Data | เลือกไฟล์รายงานดิบเข้ามาประมวลผล |
| 📤 Export Data | ดาวน์โหลดรายงานที่แปลงแล้วเป็น Excel |
| 🧹 Clear Data | ล้างข้อมูลบนหน้าจอ |

> ปุ่ม Export Data และ Clear Data จะกดไม่ได้จนกว่าจะ import data สำเร็จ

---

## 📁 ไฟล์ข้อมูลควรเก็บไว้ตรงไหน

แนะนำให้เก็บไฟล์รายงานดิบและไฟล์ export ไว้นอกโฟลเดอร์โปรแกรม เช่น:

```text
C:\LIXIL Reports\Input
C:\LIXIL Reports\Output
```

ไม่ควรเก็บข้อมูลลูกค้าจริงไว้ใน GitHub หรือส่งขึ้น online

---

## 🛑 วิธีปิดโปรแกรม

1. กลับไปที่หน้าต่างสีดำที่เปิดจาก `run_server.bat`

2. กด:

   ```text
   Ctrl + C
   ```

3. ถ้าถามว่า:

   ```text
   Terminate batch job (Y/N)?
   ```

4. พิมพ์:

   ```text
   Y
   ```

5. กด Enter

---

## ❓ ถ้าเปิดเว็บไม่ได้

ลองตรวจตามนี้:

1. เปิด `run_server.bat` แล้วหรือยัง

2. หน้าต่างสีดำยังเปิดอยู่หรือไม่

3. URL ถูกต้องหรือไม่:

   ```text
   http://127.0.0.1:5000/
   ```

4. ถ้าเปิดไม่ได้ ให้ปิดหน้าต่างสีดำ แล้วเปิด `run_server.bat` ใหม่

5. ถ้ายังไม่ได้ ให้แจ้งทีม IT หรือผู้ดูแลระบบ

---

## 🔐 ข้อควรระวังเรื่องข้อมูล

- ห้ามนำไฟล์ report จริงของลูกค้าขึ้น GitHub
- ห้ามนำไฟล์ `.xls`, `.xlsx`, `.csv`, `.zip` ที่เป็นข้อมูลลูกค้าไปเก็บใน repo
- โปรแกรมนี้ควรรัน local บนเครื่องลูกค้าหรือ server ภายในเท่านั้น
- หากใช้งานบน server ภายใน ให้จำกัดสิทธิ์เฉพาะทีมที่เกี่ยวข้อง
