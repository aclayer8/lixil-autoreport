# Changelog

All notable changes to LIXIL Auto Report are documented in this file.

## [0.4.1] - 2026-07-27

### Changed

- Added the Cisco report names to the Thai navigation labels for reports 1.2 through 1.5.
- Synchronized the navigation labels and page titles for the updated reports.
- Updated the in-app version information for the 0.4.1 release.

## [0.4.0] - 2026-06-11

### Added

- Added the CSAT report summary and table views for empty and imported states.
- Added support for Cisco Call Custom Variables Report samples.
- Added local desktop and internal server launch modes.

### Changed

- Updated Excel exports to use the imported source filename with a `converted_` prefix.
- Improved Total Calls input behavior in the CSAT report.
